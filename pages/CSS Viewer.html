CSS Viewer

полезное расширение, позволяющее идентифицировать свойство CSS в любом месте, одним движением мыши. Расширение позволяет щелкнуть на любое изображение, кнопку, текст и т.д на веб странице, и вы можете увидеть мгновенно используемый код CSS. Появится небольшое всплывающее окно с данными CSS, из которых состоит элемент.

Ключевые особенности:

Настройки и плагины обеспечивают быстрой доступ;

Мгновенно увидеть CSS код;

Простая установка.(ниже поймете)

Чтобы воспользоваться расширением, выполните следующие шаги:

step 1: Посетите программу просмотра CSS в интернет-магазине Chrome или в дополнениях для Firefox.

step 2: Теперь нажмите кнопку "Добавить в Chrome" или "Добавить в Firefox", в зависимости от используемого вами браузера.

step 3: Использовать CSS Viewer очень просто, сначала нужно запустить это дополнение, щелкнув по его значку, а затем нажав на кнопку "Пуск".

step 4: Затем просто наведите указатель мыши на изображение / текст, чтобы просмотреть свойства CSS.

step end: The end

Сслыка неа скачивание расширения -> Тык

Что может отображать?

  • Font size
  • Font family
  • Font weight
  • Line height
  • Text Color
  • Background color
  • text-align
  • Border
  • Margin
  • Padding
  • Width
  • Height
  • background-position
  • Word-spacing

Заключение

В заключение, CSS Viewer - это очень полезный и умный плагин, который может использоваться веб-разработчиками, поскольку он экономит много времени. Он не только быстр, но и показывает все свойства изображения / текста. Но имейте в виду, что для некоторых расширений требуется разрешение, что иногда приводит к утечкам данных, атакам программ-вымогателей и т.д.
